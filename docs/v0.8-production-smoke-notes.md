# v0.8 Production Smoke Notes

**URL:** https://aodxx.github.io/Personal-Utility-Hub/  
**ตรวจเมื่อ:** 17 สิงหาคม 2026  
**Browser:** Chromium sandbox viewport ประมาณ 902px wide

## สิ่งที่ยืนยันแล้ว

- GitHub Pages เปิดหน้า Hub สำเร็จและแสดง App Shell โดยไม่มี 404
- หน้า Hub แสดง catalog รวม 25 เครื่องมือ
- Quick Start แสดงเครื่องมือใหม่ 5 รายการ ได้แก่ Privacy Redactor, File Diff, Image Contact Sheet, CSV Profiler และ Audio Chapter Marker
- Audio catalog แสดง Audio Trimmer, Audio Compressor Pro, Audio Merger Studio, Silence Remover, Audio Finisher และ Audio Speed & Pitch
- Search ภาษาไทยด้วยคำว่า `รูปภาพ` ทำงานและแสดง 7 ผลลัพธ์ รวม Image Contact Sheet Studio
- Category tabs แสดงครบ 8 หมวด
- Tool cards มี full-card links, favorite buttons และ Offline preparation controls
- Production page แสดงข้อความ local-first และ privacy behavior ตาม App Shell

## ยังต้องตรวจต่อ

- Settings เปิด/ปิด, TH/EN switch และ favorite persistence บน production
- Hash navigation, back/forward และ refresh ภายใน tool route
- Mobile viewport 360 × 740 และ Pixel 7 class: overflow, icon/footer overlap, touch controls และ waveform width
- Audio workflow จริงด้วยไฟล์เสียง: select → info → configure → process → preview → export สำหรับ 6 Audio tools และ Chapter Marker
- Service Worker controller, v0.8 cache names, Offline Preparation และ reload หลังตัด network
- Production deploy ต้องเป็น commit หลัง v0.8 patch ไม่ใช่ production snapshot เก่าก่อน push

## รอบตรวจเพิ่มเติม

- Search ภาษาไทย `รูปภาพ` แสดงผล 7 รายการและรวม Image Contact Sheet Studio อย่างถูกต้อง
- Settings Center เปิดได้จาก production และแสดงภาษา/ลำดับเครื่องมือ, Compatibility Check, Offline capability และข้อความ `ไม่ใช้ Backend`
- Settings UI แสดง Browser capability checks สำหรับ File/Blob, Canvas, Web Worker, IndexedDB, Service Worker/Offline, Clipboard และ Camera

## Localization round

เปลี่ยน locale จากไทยเป็น English สำเร็จบน Production โดยหน้า Hub เปลี่ยนเป็น English ทั้ง heading, search placeholder, category labels, tool descriptions, action labels และ Settings controls ขณะที่ catalog ยังคงแสดง 25 tools และ Quick Start 5 รายการ

## Audio route round

เปิด `#/tools/audio-trimmer` บน GitHub Pages สำเร็จโดยไม่เกิด 404 หน้าแสดง category Audio & Video, Audio Trimmer heading, local processing/privacy message, offline availability และคำแนะนำ input/output WAV ขณะ lazy module กำลังโหลดตาม expected route behavior

ยังไม่มีการ upload ไฟล์เสียงจริงในการตรวจ production รอบนี้ จึงยังไม่ mark full Audio process → preview → export contract เป็น passed
