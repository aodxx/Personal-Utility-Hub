## Audio Compressor Production investigation

การเปิด Audio Compressor ครั้งแรกแสดง `Unable to load this tool` แต่ตรวจ lazy chunk บน Production พบ `audio-compressor-DhXWf1FB.js` ตอบ HTTP 200 และ direct dynamic import ใน browser สำเร็จพร้อม exports `metadata`, `mount`, `unmount` จากนั้นเปิด route ใหม่โดยตรงอีกครั้งแล้ว shared Audio Workbench mount สำเร็จ แสดง `#audio-file`, waveform และ controls ครบ

การตรวจนี้ชี้ว่าเป็น transient route/cache/load-state issue ที่ต้องทำให้ regression test และ production smoke ตรวจซ้ำหลัง hard reload/deploy ไม่ใช่สรุปว่า source module ไม่มีอยู่

Audio Compressor Production หลัง reload mount สำเร็จและ upload `audio-smoke.wav` แล้ว: การกดผ่าน coordinate browser tool ไม่ทำให้ state เปลี่ยนใน observation แรก แต่ `form.requestSubmit()` ใน browser context ทำงานและแสดง `ผลลัพธ์ / Result`, metrics `00:01.00 · 1 ch · 44,100 Hz · Peak 40.7% · 86.2 KB → 86.2 KB · Target 2.00 MB`, output preview, download button และสถานะ `ประมวลผลสำเร็จ / Processing complete` ยืนยัน processing implementation และ result contract บน Production

Audio Merger Studio Production mount และ upload ผ่าน: shared workbench แสดง audio file list, waveform, source/result preview, gap/crossfade, format selector และ Export controls หลังรับ `audio-smoke.wav`

Audio Merger Studio Production ผ่าน upload/mount และ DOM submit แสดง result `00:01.00 · 1 ch · 44,100 Hz · Peak 18.0% · 86.2 KB → 86.2 KB`, download visible และ `ประมวลผลสำเร็จ / Processing complete`

Silence Remover Production ผ่าน route mount, upload, waveform และ threshold/minimum/padding controls พร้อมสถานะอ่านไฟล์สำเร็จ

Silence Remover Production DOM submit ผ่าน: result visible, metrics `00:01.00 · 1 ch · 44,100 Hz · Peak 18.0% · 86.2 KB → 86.2 KB`, download visible และ `ประมวลผลสำเร็จ / Processing complete`
