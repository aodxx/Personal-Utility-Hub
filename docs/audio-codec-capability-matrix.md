## Policy

The matrix is evidence for the tested Chromium runtime only. UI copy must use “supported in this tested profile” or “browser-dependent” rather than promising universal codec support. If native decode fails, the application should present a meaningful error and suggest WAV or MP3 as an alternative; it must not silently claim that an unsupported input works.

No remote decoder or cloud transcoding is used by this matrix.
