# Components

พื้นที่สำหรับ UI components กลางของ Hub โดย Tool-specific UI ควรอยู่ในโฟลเดอร์ของ Tool เอง

Components กลางที่ใช้งานแล้วประกอบด้วย Search box, Category tabs, Tool card, Privacy badge และ typed 3D asset renderer ส่วน Tool-specific form, preview และ processing state อยู่ภายใน `src/tools/<tool-id>`
